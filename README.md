## 🇩🇪 Deutsch

Admin- und Diagnose-Werkzeugkasten für Windows 10 und 11. Keine Installation, keine Telemetrie, eine EXE.

### ✨ Funktionen

- 📊 **Dashboard** – Systemübersicht, Health Score, Lizenz, Berichte & Diagnose-ZIP
- 🧰 **Wartung** – DISM, SFC, Check Disk mit Live-Ausgabe, Bereinigung, Wiederherstellungspunkt
- 🌐 **Netzwerk** – Ping, Traceroute, Ports, DNS, WLAN, SMB-Freigaben, Domäne
- 🛡️ **Sicherheit** – Schnellcheck, Defender, Firewall, BitLocker, RDP-Risiko, SMBv1
- ⚙️ **Dienste & Prozesse** – verwalten per Auswahlliste, unsignierte Prozesse, Autostart
- 👤 **Benutzer** – lokale Konten anlegen, sperren, Passwort, Admin-Gruppe
- 📜 **Tools & Logs** – Ereignisse, Programme, Treiber, Tasks, GPO, HTML-Bericht

⭐ Favoriten per Rechtsklick · 🔍 Suchfeld · 🌗 Hell/Dunkel · 🇩🇪/🇬🇧 umschaltbar

### 🚀 Start

`AdminToolBox.exe` starten. Für Systemänderungen: **„Als Admin neu starten“**.

### 🔒 Datenschutz

Keine Daten an Entwickler oder Dritte. Netzwerktests erreichen nur auf Knopfdruck öffentliche Server. Logs bleiben lokal unter `C:\Temp\Alpha10-Admin-Toolbox`.

### ⚠️ Haftungsausschluss

Einige Funktionen ändern Firewall, Registry, Dienste und Konten. **Nutzung auf eigene Verantwortung** – keine Haftung für Schäden oder Datenverlust. Vorher einen Wiederherstellungspunkt anlegen.

## 🇬🇧 English

Admin and diagnostics toolbox for Windows 10 and 11. No installation, no telemetry, a single EXE.

### ✨ Features

- 📊 **Dashboard** – system overview, health score, license, reports & diagnostic ZIP
- 🧰 **Maintenance** – DISM, SFC, Check Disk with live output, cleanup, restore point
- 🌐 **Network** – ping, traceroute, ports, DNS, Wi-Fi, SMB shares, domain
- 🛡️ **Security** – quick check, Defender, firewall, BitLocker, RDP risk, SMBv1
- ⚙️ **Services & Processes** – manage via pick lists, unsigned processes, startup
- 👤 **Users** – create and disable local accounts, passwords, admin group
- 📜 **Tools & Logs** – events, programs, drivers, tasks, GPO, HTML report

⭐ Favorites via right-click · 🔍 Search box · 🌗 Light/Dark · 🇩🇪/🇬🇧 switchable

### 🚀 Start

Run `AdminToolBox.exe`. For system changes: **"Restart as admin"**.

### 🔒 Privacy

No data is sent to the developer or third parties. Network tests reach public servers only on demand. Logs stay local in `C:\Temp\Alpha10-Admin-Toolbox`.

### ⚠️ Disclaimer

Some functions change the firewall, registry, services and accounts. **Use at your own risk** – no liability for damage or data loss. Create a restore point first.
